# V5 — The Connector (The Intake)

**Title card:**
When Risk Enters the Room
Episode 5: The Intake

**Length:** 75–90 seconds

## Scene 1 — Automated collection

A connector begins importing thousands of control records.

The dashboard celebrates:

> 48,000 evidence objects collected.

The number rises rapidly.

## Scene 2 — The hidden failure

Among the imported records:

* duplicates;
* expired screenshots;
* malformed data;
* the wrong reporting period;
* untrusted text;
* records assigned to the wrong entity.

**Narrator:**
“Automation can collect evidence faster. It can also collect the wrong evidence faster.”

## Scene 3 — Irongate

The flow passes through **Irongate** before entering the governed evidence repository.

Checks appear:

* source authenticated;
* schema validated;
* entity scope confirmed;
* reporting period confirmed;
* duplicate detected;
* untrusted content quarantined;
* exception assigned for review.

Only verified records proceed.

## Scene 4 — Outcome

The dashboard changes from:

> Evidence collected

to:

> Evidence accepted, rejected, quarantined, or awaiting review.

**Narrator:**
“A connector count is not an assurance result. Ironframe validates and scopes incoming evidence before it is relied upon.”

**End card:**
IRONFRAME
Trusted intake. Controlled evidence.
Sanitize before persist.
