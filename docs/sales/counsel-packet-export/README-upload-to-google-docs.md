# Counsel packet — upload to Google Drive / Docs

These files are the LegalCORPS brief-advice attachment set (Ironframe Path B).

## How to get PDFs

1. Open Google Drive → New → Folder: `Ironframe LegalCORPS Clinic`
2. For each `.md` file below: New → Google Docs → File → Open → Upload, **or** open the `.md` in a text editor, Select All, paste into a blank Google Doc, then **File → Download → PDF**.
3. Share the folder with yourself; note the Drive folder URL if you want the agent to cite it later.
