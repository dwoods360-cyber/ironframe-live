# V2 — The Audit Request (The Evidence)

**Title card:**
When Risk Enters the Room
Episode 2: The Evidence

**Length:** 75–90 seconds

## Scene 1 — The request

An internal auditor sends a message:

> Please provide evidence that the access-review control operated for the second quarter.

The compliance manager opens five applications.

Tabs multiply across the screen:

* shared drive;
* ticketing system;
* cloud console;
* email;
* spreadsheet;
* screenshots folder.

**Narrator:**
“The control may have operated. Proving it is another matter.”

## Scene 2 — The scramble

A screenshot has no date.

A spreadsheet contains three conflicting versions.

An email attachment has been renamed.

A reviewer asks:

**Auditor:**
“Where did this evidence come from?”

The compliance manager hesitates.

## Scene 3 — Ironframe

The Ironframe control record appears.

It shows:

* control objective;
* responsible owner;
* evidence source;
* collection date;
* reporting period;
* reviewer;
* exceptions;
* remediation;
* approval history.

The auditor opens the source record and follows the complete chain.

**Narrator:**
“Ironframe connects evidence to the control assertion it supports. Source, owner, period, review, exceptions, and changes remain visible.”

## Scene 4 — Outcome

The auditor marks the request complete.

The compliance manager closes the spreadsheet folder without opening it.

**Narrator:**
“Evidence should not merely exist. An independent reviewer should be able to reconstruct what happened.”
