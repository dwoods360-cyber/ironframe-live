When board reporting pulls from a shared register, entity scope is the first thing to inspect.

Operators in multi-client or multi-subsidiary environments already know the painful version: one export, one slide deck, one “enterprise” view — and a quiet question about whether the wrong entity’s evidence could ride along.

Before the next board or customer assurance send, walk one bounded path:

1. Which entity owns each artifact in the export?
2. What date was each control last validated — not last documented?
3. Who authorized cross-boundary promotion?
4. If the dashboard aggregates risk, can you still trace back to scoped evidence without a shared-table filter?

Most demos still show screens. Fewer show a defendable entity-scoped export path.
