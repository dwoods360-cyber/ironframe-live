# V3 — The Wrong Client (The Boundary)

**Title card:**
When Risk Enters the Room
Episode 3: The Boundary

**Length:** 75–90 seconds

## Scene 1 — Managed service provider

An analyst prepares a report for Client A.

The report loads.

For a fraction of a second, a control record belonging to Client B appears in the results.

The analyst freezes.

**Analyst:**
“That should not be here.”

## Scene 2 — The hidden risk

The screen shows a shared platform serving several clients and subsidiaries.

**Narrator:**
“Multi-client and multi-entity systems depend on more than labels. Every query, export, background job, support action, and administrative privilege must remain inside its authorized boundary.”

## Scene 3 — Ironframe

Ironframe displays:

* workspace identity;
* user role;
* row-level policy;
* entity scope;
* query scope;
* export restriction;
* privileged action log.

A cross-tenant request is denied.

An alert records the attempt.

**Narrator:**
“Ironframe applies governed isolation throughout the workflow—not only at the interface.”

## Scene 4 — Proof

An auditor opens an isolation test report.

The report shows permitted and denied test cases.

**Narrator:**
“Separation is not established by saying clients are separate. It is established by controls that can be tested.”
