Your GRC agent drafted a control narrative in twelve seconds.

That is not evidence.

Speed is not provenance. A fluent paragraph is not an attestation. And “the model said so” is not an authorization trail an auditor—or a board—can defend.

What breaks first is usually the promotion path:

• AI output lands in the same cabinet as reviewed evidence  
• No quarantine step before trusted use  
• No bound source / model / prompt context  
• No human approval before board or client export  

A practical control test this week:

1. Pick one AI-assisted sentence that appeared in a report, ticket, or control assertion.  
2. Ask: who approved promoting it from draft to trusted evidence?  
3. Ask: can you show source inputs, time, scope, and reviewer—not just the final text?  
4. If the answer is “the agent wrote it into the system,” you’ve found the next gate to redesign.

Control-first pattern for AI in GRC:

• Treat model output as untrusted ingest  
• Quarantine before trusted persistence  
• Human authorization before board or cross-entity publication  

Not more copilots. Clear promote gates.
