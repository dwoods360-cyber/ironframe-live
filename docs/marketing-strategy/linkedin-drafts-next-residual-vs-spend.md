Knowing the estimated exposure is only half the board conversation.

The other half is: if we spend $X on this control, what happens to residual exposure—and which assumptions changed?

Most programs can show a control status. Fewer can show a defendable before/after:

• Estimated exposure (whole cents, explicit assumptions)  
• Proposed mitigation cost  
• Residual exposure after the control change  
• Who approved the assumption set  

Without that loop, budget meetings become opinion contests: “this feels High” versus “we already bought the tool.”

What to inspect this week:

1. Pick one funded security or compliance initiative.  
2. Ask for the pre-change estimated exposure and the post-change residual—same scenario, same units.  
3. Ask which assumptions moved (frequency, loss magnitude, control effectiveness)—and who signed them.  
4. If you only have a completed checkbox and a color, the capital decision is still undocumented.

Boards don’t need more status. They need a path from control spend to residual exposure they can challenge.
