# General Counsel and the Draft That Almost Escaped

The message appeared in Rachel’s review queue at 6:43 p.m.

An AI assistant had drafted a customer notification concerning an active security investigation. The language sounded polished, calm, and certain.

It was also wrong.

The draft stated that no customer data had been accessed. Investigators had not reached that conclusion. It described the event as contained, although one environment remained under review. It also included details Rachel believed should remain privileged.

At another company, the message might already have been sent.

Here, it had stopped at the perimeter.

The system marked the document as a draft, identified the source material used to generate it, and routed it to designated reviewers. It could not publish itself.

Rachel removed the unsupported sentence, narrowed the description of the investigation, and sent the revised language to the incident commander and communications lead for approval.

Only after the human reviewers signed off did the message leave the organization.

The next morning, Rachel looked at the activity record. Every generated sentence, revision, approval, and publication step remained visible.

The value was not that the machine had written quickly.

The value was that it had been unable to speak for the company without permission.
